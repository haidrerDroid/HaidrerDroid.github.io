## 🔭 Future Projects and Research Interests

### 1. Universal UEFI Simulator for Snapdragon Devices

Researching the design of a universal UEFI simulation and testing environment for Snapdragon-powered devices.

The long-term goal is to investigate UEFI firmware behavior, ARM64 boot flows, platform compatibility, and operating system bootability in a controlled development environment.

**Planned research areas:**
- Study UEFI architecture and EDK II.
- Explore ARM64 UEFI boot flows using QEMU.
- Investigate firmware compatibility across Snapdragon platforms.
- Understand device initialization, hardware abstraction, and firmware interfaces.
- Test alternative operating system boot scenarios in virtualized environments.
- Explore the differences between simulated firmware and real-device firmware implementations.
- Investigate the technical requirements for porting or adapting UEFI to compatible physical devices.

*Note: Simulation does not guarantee compatibility with physical devices; actual hardware support depends on device-specific firmware, drivers, and platform implementation.*
